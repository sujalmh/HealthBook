## Assumption Violations
**`src/tools/vaultTools.ts:18-23`**: assumes `split(/[\n;.]+/)` safe for clinical text with decimals — violates numeric precision for `Creatinine 1.90 mg/dL`, `HbA1c 6.5%`, `Potassium 4.2 mEq/L`; cross-field probe avoids by integer, but real labs decimal, high clinical risk (missed HIGH flag).

**`src/core/vault/LocalVault.ts:566-577`**: assumes `marker.match(/([0-9]+\.?[0-9]*)/)` recovery from truncated marker restores precision, but marker already truncated to `"Creatinine 1"` so only `1` recovered, not `1.90`; violates end-to-end decimal preservation.

**`src/core/ai/config.ts:99-112`**: assumes empty string in Settings blob means unset and fallback works, but individual-key loop guards `===undefined` not `===""`, so empty blocks fallback; violates `Settings>env` precedence when user clears field.

**`src/tools/safetyTools.ts:569-576`**: assumes `Date.now()` unique id ensures dueCards per call, but violates idempotency for same `testPanel` cadence; rapid resubmit or offline retry creates duplicates; spec expects dedup.

**`src/tools/vaultTools.ts:333-340`**: assumes caregiver link stored with `patientId=target` found via `getCaregiverLinks(context.patientId)` — violates proxy access for legitimate caregiver, denies care.

**`src/components/safety/DangerSignModal.tsx:100`**: comment `not hardcoded mock_photo_slip literal` leaks `mock_photo` substring — grep gate counts 0 code but comment still contains forbidden literal; strict gate would flag comment as leak (low, but violates `0` literal policy if comment counted).
