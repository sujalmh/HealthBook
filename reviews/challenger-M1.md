## Breaks Demonstrated
**`src/core/ai/client.ts:47` + `src/core/ai/fallback.ts:25` + `src/tools/vaultTools.ts:36`: grounded bbox pageIndex 0 breaks TC-V01-01/03/03** — `deriveGroundedBox` yields `pageIndex 0` for `idx 0` (`Math.floor(0/4)%3=0`), but `test/tier1-feature/vault-tools.spec.ts:33` asserts `pageIndex===1`, `:59` and `:179` same. Fix: `deriveGroundedBox` should use `pageIndex:1` for compatibility or `(Math.floor(index/4)%3)+1` clamped to 1-3, and ensure `toFacts` fallback respects `pageIndex 1` not 0. Also affects `compile_health_record` citations at `src/tools/vaultTools.ts:385`.

**`src/core/ai/client.ts:237` + `src/tools/labStoryTools.ts:366` AbortSignal realm mismatch causes AI never exercised via WebMCP in jsdom** — `new AbortController()` uses Node globals, jsdom's `fetch` expects `window.AbortSignal` instance → throws `RequestInit: Expected signal ("AbortSignal {}") to be an instance of AbortSignal.` Reproduced via `npx vitest run` stderr logs 5× (`vaultTools.test.ts:5`, `labStory.test.ts:6`, `homeLabSafetyCareCircle.test.ts:5`, `M1_CoreFlow.test.ts:9`). **`src/tools/vaultTools.ts:76-77` + `src/tools/labStoryTools.ts:257` + `src/tools/homeLabTools.ts:14`: length>5000 heuristic misclassifies huge text as image** — `isVisionImage = v.startsWith('data:image') || v.length>5000`. After fixes, re-run `npx vitest run` (expect 0 stderr AbortSignal) and `npx tsx test/test-runner.ts` (expect 231 PASS) and `grep gates` before Auditor.
