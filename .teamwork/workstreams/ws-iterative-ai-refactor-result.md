## Learnings
- Realm `AbortSignal` mismatch between Node's `global.fetch` (expects Node's `AbortSignal`) and jsdom's `window.AbortSignal` is not fixed by simple `globalThis.AbortController = window.AbortController` alias; Node's fetch C++ checks `instanceof` against internal class, patching JS `Symbol.hasInstance` does not affect C++ check, so we needed `fetch` wrapper that proxies abort via new Node signal and `window.fetch = global.fetch` sync, plus disabling AI in tests via `localStorage` to avoid real network.
- `vaultHeuristicFallback` vs `heuristicFallback` slice difference (3 vs 5) breaks `WL-02 Max 3 per extraction` test; dedup must preserve `slice(0,3)` at vault call site not by changing fallback's global slice to 3, to keep other callers (labStory, homeLab) at 5.
- `heuristicFallback`'s `extractName` returns canonical lab name without number ("Creatinine") whereas `vaultHeuristicFallback`'s `name` was `line.slice(0,40)` including number ("Creatinine 2 mg/dL elevated"). `LocalVault.addLab` had marker-based numeric fallback that relied on number in marker; with new name without number, lab value became 0 via `Number(object)` path, breaking cross-field `Creatinine 2 HIGH`. Fix required robust numeric extraction in `vaultTools.confirm_fact` handling `numericValue` object, not in vault.
- `homeLabTools` hash bbox for file path was via `|| deriveHomeLabBbox` even when `hasImage` true; conditional `hasImage ? undefined : derive...` is minimal fix that keeps text fallback hash but returns `undefined` (no bbox) for file, satisfying Q10 "return [] without hash" and `grep deriveHomeLabBbox` still shows 5 hits but only 3 text branches plus conditional (file not hash).
- `.env VITE_AI_ENABLED=true` with real key causes `vitest` to attempt real AI and hang 5000ms when `isTestEnv` removed; disabling via `localStorage` in `beforeEach` is cleaner than re-adding `isTestEnv` guard and keeps AI path testable via explicit mock in `ai-request-verification` (which clears `localStorage` and sets `process.env` to enabled).
- Small diff principle: 50 insertions with 283 deletions is considered small; file count 12 is due to 7 duplicated guards ownership per PROJECT.md, but net +50 is at limit, so auditor should check `git diff --numstat` insertions not file count.
