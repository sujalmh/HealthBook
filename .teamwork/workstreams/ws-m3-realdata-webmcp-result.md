## Learnings
- `export * from '../../test/fixtures/legacyMocks'` without `.ts` extension causes `ERR_MODULE_NOT_FOUND` in `node` strip-only but works in Vite; adding `.ts` extension fixes runner while keeping Vite build 1659. Lesson: keep fixture re-exports explicit for both runtimes.
- `labStoryTools` NaN guard must be at both `normalizeLabBiomarker` (safeRawValue) and `extract_labs` rawLabData mapping (`Number.isFinite` filter) to prevent `normalizedValue: NaN` from `"abc"` malformed strings (boundary test `T2-05` expects no crash, now `vault.addLab` stores 0 instead of NaN).
- `careCircleTools` devi heuristic is substring-based (`includes('devi')`) and fails `we0`/`slop0` grep if left; replacing with vault-derived `onBehalfOf || name || patientId` satisfies real-data and keeps `act_on_behalf` audit generic (`Patient` not Shanti) while requiring tier1/e2e tests to update expectations from exact Shanti to `assert(!!patientName)` flexible check. This decouples tools from mock literals and makes chat apps work for any created user.
- `test/harness` default patientId must be generic `test-patient-001` to prove empty vault for created user, not `patient-s-devi` legacy; but caregiver tests that use `p_devi_78` still need Shanti-like name via harness derived mapping — kept conditional `patientId.includes('devi') ? 'Smt. Shanti Devi'` inside harness (test-only, allowed) while `src` is 0. This isolates mock to test harness (allowed per REQUEST `Remove user mock data only; keep drug_knowledge` and `grep mockShanti src 0` not `test`).
- `DocumentDropzone` Browse Files button `py-2` gives ~36px height, failing 44px touch target for mobile audit; changing to `py-2.5 min-h-[44px] min-w-[120px]` satisfies 44px without visual change, verified via screenshot at 320.
- `puppeteer-core` with `Chrome /Applications/Google Chrome.app` is more reliable than `browser.open` for localStorage manipulation (requires `page.evaluate` to clear/set and `page.reload` after). Capturing 6 viewports sequentially per page (new Page per viewport) ensures isolation; sharing localStorage across pages requires clear then reload per viewport, otherwise gate shows vault (as seen in first capture run where 375 gate incorrectly showed vault).
- Preserving `max-w-md mx-auto` for gate vs `max-w-7xl mx-auto` for vault shell ensures no flex gaps at 320/1440; `truncate` 109 intact via `truncateName` 64 and `truncate` class on `patientShort`, verified at 6 viewports (gate card stays centered, not full-width).
