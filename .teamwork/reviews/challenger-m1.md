## Assumption Violations
**`tailwind.config.js:48` Inter fontFamily assumes loaded**: no `<link>`/`@import` in `index.html` or `src/index.css`. Assumes OS fallback system-ui is acceptable; spec says `fontFamily Inter` but no loading strategy. If figma expects Inter metrics, headings will be off 2-4px. Hardening: add `https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700;800` or document system fallback intentional — violations is design-accuracy, not crash.

**`src/index.css:23-29` heading tokens assume usage**: `h1 text-heading-xl 30px/800` assumes pages use bare `<h1>`; but `src/App.tsx:155` overrides with `text-base font-black`, so token never paints in header. Assumes M3 modules will adopt `text-heading-*` but currently dead code (purged from dist). Violates "typography scale added" visibility criterion.

**`src/App.tsx:83-88` 44px min assumes uniform interactive size**: Assumes no tiny badges/icons; globally forces `button {44px}` making `w-4` badges expand at <640. Violates pill-tab/mini-button expectations.

**`src/index.css:52-59` scrollbar-none assumes users know scrollable**: Assumes hidden scrollbar still discoverable via swipe; keyboard Tab scroll not announced. Violates a11y 2.4.7 focus visible affordance.

**`src/App.tsx:340` bottom nav truncate assumes 8 labels fit 64px**: `max-w-[64px] truncate` assumes "Medicine Review" (15 chars) truncates to "Medicine…" — ok but at 320 loses meaning vs icon-only. Assumption that truncation is acceptable UX.
