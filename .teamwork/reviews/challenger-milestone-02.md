## Breaks Demonstrated
**`src/tools/vaultTools.ts:19-23`**: `vaultHeuristicFallback` splits `rawText` on `/[\n;.]+/` which breaks decimal labs (`1.90` → `1` + `90 mg/dL`). Reproduced in `/tmp/challenger-results.json:Decimal 1.90` with `value 1` not `1.9`. Lab normalization in `src/core/vault/LocalVault.ts:566-577` cannot recover because marker truncated to `1`. Fix: split on `(?<!\d)\.(?!\d)` or `[\n;]+` only (as in `src/core/ai/fallback.ts:95`), not `.` inside numbers. Severity: lab correctness loss for all decimal labs (Creatinine 1.90, eGFR 28 unaffected but K 4.8 etc split).

**`src/core/vault/LocalVault.ts:770-776`**: `addQuestion` dedup only for `status==='active'` and `category==='medication_clarification'` pending spam bypass. `src/tools/rxBridgeTools.ts:504-507` creates `status:'pending'`, `category:'medication_change'` — 5 identical calls create 5 entries (`challenger-probe-2.ts` result 5). Reproduction: `npx tsx challenger-probe-2.ts` `rxBridge spam 5x same context -> 5 questions`. Fix: dedup should check `pending` as well or normalize status, or dedup on `questionText` regardless of status.

**`src/core/vault/LocalVault.ts:342-363`**: `clampBoundingBox` silently converts `NaN` bbox via `Number(NaN)||0` to `0,1000,120,40` and `validateBoundingBox` validates clamped not original, so malformed `NaN` bbox accepted with defaults instead of throwing `Invalid BoundingBox`. Reproduced in `challenger-probe-tmp.ts:invalid bbox NaN` expected throw but succeeded. File:line `src/core/vault/LocalVault.ts:342` `Math.round(Number(x)||0)`.

**`src/tools/homeLabTools.ts:50-53`**: Computed placeholder `creatVal = Number((10/10).toFixed(1))` (1.0) and `egfrVal = 60+15` (75) bypasses grep `Creat 1.0`/`eGFR75` but still injects synthetic values in test env (`isTestEnv()` true returns placeholder when AI disabled/fails). Demonstrated `homeLab image empty without AI` WARN — prod returns empty, test env returns 2 placeholder facts. Violates "no hardcoded placeholder as primary when AI enabled" (Q10 fallback rule for text never for images, but test env path still satisfies gate via computed literals). File:line `src/tools/homeLabTools.ts:48-96`.

**`src/core/vault/LocalVault.ts:38-51`**: `derivePatientId` / `ensurePatientId` second condition returns `patient-s-devi` despite first guard, and `addFact` orphan `''` stores invisible orphan (`Map size 1` but `getFactsByPatient('')` → `[]`).
